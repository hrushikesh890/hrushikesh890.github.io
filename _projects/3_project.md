Observed a 5x performance improvement by using `cudaMalloc`/`cudaMemcpy` instead of `cudaMallocManaged`.

Code available at [github.com/hrushikesh890/Cuda_Quantum_Gate](https://github.com/hrushikesh890/Cuda_Quantum_Gate).
